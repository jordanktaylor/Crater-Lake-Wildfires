Wildfires of Crater Lake in Oregon (1992-2020)

by Jordan Taylor

Description

This map shows the locations of wildfires within a 5-mile radius from Crater Lake in Oregon. Data labels appear when zoomed in, displaying information about the Wildfire Class of the fires and the data that they were discovered.

Map details

Created on QGIS version #3.44.15 using OpenStreetMap. Data boundaries derived from the QuickOSM plugin. © 2022 Openstreet map contributors.

Wildfire Data Source: Spatial wildfire occurrence data for the United States, 1992-2020. https://www.fs.usda.gov/rds/archive/catalog/RDS-2013-0009.7
